# スタッフ画像未設定時の登録エラー修正 引き継ぎ

## 変更ファイル

- `core/serializers.py`
- `core/test_staff_optional_email.py`

## 修正内容

- スタッフ新規登録APIで `avatar_url` の空文字を許可した。
- 管理画面が画像未設定時に送る実際のリクエストと同じく、`email` と `avatar_url` が空文字でもスタッフを登録できる回帰テストを追加した。
- migrationは作成していない。

## 発見経緯

本番フルチェックで、メールアドレスを未入力にしたスタッフ新規登録を実行したところ、任意項目である画像URLの空文字がAPIで拒否されることを確認した。メール任意化とは別の既存不整合だが、スタッフ登録の完了を妨げるため最小hotfixとして修正した。
