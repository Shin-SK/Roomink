# セラピスト予約確認・接客完了操作 引き継ぎ

## 対応内容

- セラピストの予約一覧とマイページの予約カードに以下を追加
  - 予約名
  - コース名・料金
  - 選択済みオプション
  - 指名区分・指名料
  - 支払い方法
  - 合計金額
- セラピスト本人が担当予約のオプションを選択・変更できる操作を追加
- 予約確認後の確定予約に「接客開始」を追加
- 接客中または会計待ちの予約に「接客終了・売上へ反映」を追加
- セラピストの終了操作で予約を `DONE` にし、本日の売上・給与見込みへ即時反映
- マイページの売上説明を新しい完了条件に合わせて更新

## 安全条件

- 自分以外のセラピストの予約は操作不可
- 別店舗のオプションは選択不可
- 完了・キャンセル済み予約のオプション変更は不可
- カード決済確認済みかつオプション代をカードに含む予約は、セラピスト側でのオプション変更不可
- 予約確認前は接客開始不可
- 支払い方法未設定の予約は接客終了不可
- 操作したセラピストを `updated_by` に保存

## API

- `POST /api/cast/orders/<id>/options/`
- `POST /api/cast/orders/<id>/start/`
- `POST /api/cast/orders/<id>/complete/`

`GET /api/cast/today/` には予約名、オプション、指名料、支払い方法、合計金額、および店舗で選べるオプション一覧を追加した。
