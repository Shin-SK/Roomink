# R’s SPA アカウント発行・利用開始手順

## 目的

R’s SPAへ登録済みの店舗・キャスト・各種設定を作り直さず、実際に利用するスタッフとキャストへ個別アカウントを渡す。

## 現在地（2026-08-31 読み取り確認）

- R’s SPAは専用店舗として分離済み
- R’s SPA専用マネージャーアカウントは発行済み
- R’s SPAへキャスト26名が登録済み
- 上記26名は、まだ本人用ログインアカウントが未発行
- 現在入力済みの内容はR’s SPAへ所属しており、東京メンズエステとは混在していない

## 運営スタッフ／マネージャーの発行

1. R’s SPAのマネージャーでRoominkへログインする
2. `設定 → スタッフ管理` を開く
3. `スタッフ追加` を押す
4. ユーザー名、仮パスワード、権限を入力する
5. 保存後、ログインURL・ユーザー名・仮パスワードを本人へ個別に共有する
6. 本人がログインでき、R’s SPAの情報だけが見えることを確認する

権限の目安:

- マネージャー: アカウント発行、マスター設定、過去予約修正などを含む管理者
- スタッフ: 予約受付・当日運用を担当。管理設定の変更は不可

## キャスト本人用ログインの発行

1. R’s SPAのマネージャーでログインする
2. `設定 → キャスト管理` を開く
3. 対象キャストの編集画面を開く
4. `本人用ログイン` へユーザー名と8文字以上の仮パスワードを入力する
5. `ログインを発行` を押す
6. 表示された共有文をコピーし、本人へ個別に渡す
7. 本人がログインし、キャスト用マイページを開けることを確認する

発行済みの場合、ユーザー名は固定される。必要な場合は同じ画面から仮パスワードだけを再設定する。

## 共有時の注意

- LINEグループ等へ全員分をまとめて貼らず、本人へ個別に送る
- 複数人で同一アカウントを共有しない
- 退職・利用停止時は、そのアカウントを無効化または削除する
- 実際のログイン確認が終わるまで、元のマネージャーアカウントは消さない

## 最初の利用開始チェック

- manager: R’s SPAだけが表示され、スタッフ／キャストを発行できる
- staff: R’s SPAだけが表示され、予約の作成・変更ができる
- cast: 本人のキャスト画面と本人に関係する情報だけが表示される
- 別店舗IDをURLやAPIへ直接指定しても、閲覧・更新できない
