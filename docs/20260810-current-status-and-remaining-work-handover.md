## 未実装の業務機能

### 優先度：高

1. 予約の連絡者と実利用者の分離
   - 電話番号は顧客アカウントごとに一意のまま維持する。
   - 予約へ「実利用者名」を保存し、代表者Aの連絡で利用者Bを予約できるようにする。
   - 将来、本人が特定できた場合だけ過去履歴へ関連付ける。自動統合は行わない。
2. シフト終了70分前アラート
   - `alert_at = shift_end - 70分` を起点とする。
   - `alert_at`以降のシフト時間帯に重なる有効予約が1件もない場合だけ通知する。
   - 例：`alert_at=20:50`で20:30〜21:30の予約がある場合は、時間帯が重なるため通知しない。
   - まず運営画面、次にLINE等の外部通知を追加する。
3. キャスト側の複数日シフト一括申請

### 優先度：中

4. キャストの希望エリア順位（第1〜第5希望）
5. 一般向けWeb予約
   - 新規顧客向け公開ページ。
   - `一時hold → SMS本人確認 → 最終空き確認 → atomicに確定`を基本候補として再精査する。
   - 同時予約競合とSMS未確認の枠占有を安全に扱う。
   - 予約確定後に顧客招待／SMSへ接続する。
   - 現場試用を先に安定させた後、最後に実装する。
6. 70分前アラートのLINE自動通知・当日サマリー拡張
7. 代表予約から既存顧客へ履歴を手動関連付けする運用UI
